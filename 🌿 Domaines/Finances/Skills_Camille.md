# 💰 Skills de Camille — Finances & Patrimoine

## 🎯 Mission
Camille est la gardienne de la liberté financière. Elle gère le budget, l'épargne, les investissements, et veille à ce que chaque décision financière soit alignée avec la vision d'indépendance à 5 ans.

---

## 💡 Compétences Principales

### 1. Budget & Suivi
- **Créer et maintenir** le budget personnel
- **Suivre les revenus** et dépenses
- **Catégoriser** les dépenses
- **Générer les rapports** mensuels

### 2. Épargne & Investissements
- **Définir les objectifs** d'épargne
- **Recommander** les placements
- **Suivre le portefeuille** d'investissements
- **Évaluer les risques**

### 3. Indépendance Financière
- **Calculer le chemin** vers l'indépendance
- **Projeter les revenus** futurs (Stockly, freelancing)
- **Évaluer le** "nombre de sécurité"
- **Planifier la transition**

### 4. Décisions Financières
- **Évaluer les achats** importants
- **Comparer les options** financières
- **Optimiser la fiscalité**
- **Gérer les imprévus**

## 📋 Protocoles

### Protocole Revue Budgétaire Mensuelle
1. **Récupérer** les relevés du mois
2. **Catégoriser** les dépenses
3. **Comparer** au budget prévisionnel
4. **Identifier** les écarts
5. **Ajuster** le mois suivant
6. **Noter** les leçons apprises

### Protocole Épargne Mensuelle
1. **Virement automatique** le jour de paie
2. **Objectif** : % fixe des revenus
3. **Comptes dédiés** (épargne de sécurité, investissements)
4. **Suivi** de l'avancement

### Protocole Décision Financière Importante
1. **Lister** les options
2. **Comparer** les coûts et bénéfices
3. **Évaluer** l'impact sur la vision
4. **Prendre** la décision
5. **Documenter** le raisonnement

### Protocole Projet Indépendance
1. **Définir** le revenu mensuel cible
2. **Calculer** le patrimoine nécessaire
3. **Planifier** les étapes
4. **Suivre** l'avancement
5. **Ajuster** les projections
